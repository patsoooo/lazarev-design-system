Перемикач вмикає або вимикає налаштування. Зміна застосовується одразу, без підтвердження.

Складається з доріжки-пігулки та круглого повзунка. Стан читається і кольором повзунка, і його позицією.

## Коли використовувати

- Для двійкового налаштування, яке вмикається негайно.
- Коли стан має бути видимим без додаткових дій користувача.

## Коли не використовувати

- Для вибору між кількома варіантами — для цього є інші елементи керування.
- Для дії, яку треба підтвердити. Використовуйте [Button](/components/button).
- Якщо зміна застосовується лише після відправлення форми — там доречніший чекбокс.

## Анатомія

| Елемент | Опис | Обов'язковий |
| --- | --- | --- |
| Доріжка | Пігулка-контейнер, фон не змінюється між станами | Так |
| Повзунок | Круг, що змінює колір і позицію | Так |

## Токени

<div className="ds-table">

| Властивість | Токен |
| --- | --- |
| Фон доріжки | `button/toggle/bg` |
| Повзунок, вимкнено | `button/toggle/inactive` |
| Повзунок, увімкнено | `button/toggle/active` |
| Заокруглення | `button/toggle/radius` — 32px |
| Розмір доріжки | 28 × 16px |

<Warning>
  Розміри підтверджені з дизайном, але змінних під них у групі `button/toggle` немає — там лише три кольори й радіус. Наступний експорт із Figma знову прийде без розмірів, тож заведіть їх, інакше значення житимуть тільки в цій документації.
</Warning>

<Warning>
  Проміжних станів немає. Hover, Pressed, Inactive та Disabled у макеті не описані — [уточнити], чи вони потрібні.
</Warning>

## Правила

<Check>
  Показуйте стан і кольором, і позицією повзунка. Колір поодинці недоступний для користувачів із порушенням сприйняття кольору.
</Check>

<Check>
  Формулюйте підпис так, щоб увімкнений стан означав «так». Наприклад, «Показувати сповіщення», а не «Приховати сповіщення».
</Check>

<Warning>
  Не використовуйте перемикач там, де зміна не застосовується миттєво. Користувач вважатиме, що налаштування вже збережене.
</Warning>
