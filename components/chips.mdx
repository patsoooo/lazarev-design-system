Чип — компактна пігулка для фільтра або мітки. Використовується наборами: кілька чипів стоять поруч, і користувач вмикає потрібні.

Складається з лейбла та трейлінг-стрілки ↗. Форма й висота ті самі, що в [Button](/components/button), але чип завжди контурний у стані спокою.

## Коли використовувати

- Для фільтрів, які вмикаються й вимикаються без перезавантаження вмісту.
- Для набору міток, з якого користувач обирає один або кілька варіантів.

## Коли не використовувати

- Для головної дії на екрані. Використовуйте [Button](/components/button).
- Для перемикання розділів сторінки. Використовуйте [Tab](/components/tab).
- Поодиноко: один чип на екрані читається як кнопка, що не спрацьовує.

## Правила

<Check>
  Ставте чипи набором. Користувач має бачити, з чого обирає.
</Check>

<Check>
  Пишіть лейбли коротко й однією формою — одним словом або однією фразою для всього набору.
</Check>

<Warning>
  Не змінюйте висоту чипа під довгий текст. Якщо лейбл не вміщається, скорочуйте текст, а не розтягуйте пігулку.
</Warning>
