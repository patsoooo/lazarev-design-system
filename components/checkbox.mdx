Чекбокс вмикає або вимикає окремий пункт. На відміну від [Toggle](/components/toggle), зміна зазвичай застосовується не одразу, а після підтвердження форми.

Має два незалежні виміри: **вибір** (Unchecked або Checked) і **наведення** (Default або Hover). Тому станів чотири.

Той самий елемент використовується як пункт списку в [Dropdown](/components/dropdown).

## Коли використовувати

- Для набору незалежних пунктів, з яких можна обрати кілька.
- Для згоди з умовою перед відправленням форми.

## Коли не використовувати

- Для налаштування, яке застосовується миттєво. Використовуйте [Toggle](/components/toggle).
- Для вибору одного варіанта з кількох взаємовиключних.

## Анатомія

| Елемент | Опис | Обов'язковий |
| --- | --- | --- |
| Контейнер | Квадрат із заокругленням і межею | Так |
| Галочка | З'являється у стані Checked | Лише коли обрано |
| Лейбл | Текст поруч із чекбоксом | Залежить від контексту |

## Токени

<div className="ds-table">

| Властивість | Токен |
| --- | --- |
| Межа | `checkbox/border` |
| Межа на Hover | `checkbox/border-hover` |
| Товщина межі | `checkbox/border-width` |
| Заокруглення | `checkbox/radius` |
| Колір галочки | `checkbox/check-icon` |

</div>

<Warning>
  Група `component.checkbox` містить лише ці п'ять токенів. Стани Disabled, Focus та Indeterminate не описані — [уточнити], чи вони потрібні.
</Warning>

## Правила

<Check>
  Робіть клікабельним і чекбокс, і його лейбл. Ціль розміром у 24px замала для впевненого влучання.
</Check>

<Check>
  Формулюйте лейбл ствердно, щоб позначка означала «так». «Надсилати листи», а не «Не надсилати листи».
</Check>

<Warning>
  Не використовуйте чекбокс для взаємовиключного вибору. Якщо варіант може бути лише один, чекбокси вводять в оману.
</Warning>
